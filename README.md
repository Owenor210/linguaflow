# LinguaFlow 1.0 — Telegram Mini App (frontend MVP)

React + Vite застосунок для вивчення англійської, **без дуелей**.

## Запуск

```bash
npm install
npm run dev
```

У GitHub Codespaces відкрийте вкладку **Ports** та порт **5173**, або відкрийте локально `http://localhost:5173`.

Для production збірки:

```bash
npm run build
```

Готові статичні файли з'являться в `dist/`.

## Що реалізовано

- Темний адаптивний інтерфейс із котиком-маскотом
- Рівні A1–C1
- 10 демонстраційних уроків (по 2 на рівень)
- Картки слів, тести, пояснення помилок
- XP, щоденна серія, прогрес за рівнями
- 3 нові безкоштовні уроки на день, повторення пройдених без ліміту
- Профіль, ім'я з Telegram WebApp за наявності
- Інформаційна сторінка Premium: 49 Stars / 7 днів, 149 Stars / 30 днів

## Обмеження

**Це frontend MVP, не готова комерційна платформа.**

- Прогрес зберігається в `localStorage` конкретного браузера. Його можна стерти, і він не синхронізується між пристроями.
- `Telegram.WebApp.initDataUnsafe` використовується **лише для відображення імені**, а не для безпечної авторизації. Для серверної авторизації обов'язкова перевірка `initData` на сервері.
- Telegram Stars **ще не інтегровано**. На сторінці Premium немає кнопок, що імітують оплату. Для реальної оплати потрібні серверні інвойси в XTR, `pre_checkout_query`, `successful_payment`, облік терміну доступу, `/paysupport` і повернення коштів.
- Розширені вправи, розширена аналітика, серверний ліміт уроків, рекламна атрибуція, адмін-панель та онлайн-дуелі не реалізовані.
- Уроки демонстраційні; для запуску навчального продукту потрібно розширити контент і провести методичну перевірку.

## Підключення до Telegram

1. Розмістіть `dist/` на HTTPS-хостингу.
2. У BotFather налаштуйте Mini App/Menu Button на публічний HTTPS URL.
3. Відкрийте Mini App із Telegram.

Цей ZIP — самодостатній новий проєкт. Якщо у вашому репозиторії вже є код, зробіть резервну копію та переносьте файли обережно, а не перезаписуйте все без перевірки.
